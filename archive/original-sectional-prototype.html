Sectional test

A standalone CAT-style practice interface. Choose a section and start a 40-minute test. Your answers and per-question time are tracked in this browser tab.

Question data can be added now or later. If you leave it blank, the app loads a small demo set so you can test the interface.
MCQ answer is a zero-based option index (0 = first option, 1 = second). TITA uses a typed answer. The answer field is optional and is used only in the post-test review. You can include a shared passage in each relevant question, or group questions using the same passage text.
Test behaviour
  • 40-minute default countdown; the test auto-submits when time runs out.
  • Question-level time tracking, question palette, Previous/Save & Next, Mark for Review, Clear Response, and Submit.
  • Statuses: Not Visited, Not Answered, Answered, Marked for Review, and Answered & Marked for Review.
  • Question content and answers remain in this session; this file does not send data to a server.
